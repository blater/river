# P01/P04/U05 promotion review

Date: 2026-08-15

Status: passed for the current M5 reference set

## Decision

P01, P04, and U05 satisfy their bounded current contracts. This decision does
not create direct Ingres compatibility or promote G0, U06, or M5.

## Evidence reviewed

- The project-owner provenance decision and ADR approve the external Ingres
  source and historical tests as references rather than vendored inputs.
- The v2 ledger records canonical upstream URLs, imported SVN revisions,
  license notice locations, acquisition mode, and reproducible tree identities.
- Gradle resolves every external JAR, compares it to the ledger, and requires
  fail-closed SHA-256 verification metadata without trust/ignore bypasses.
- The explicit reference gate reproduces the source and test tree identities
  and independently verifies all three selected matrix-file hashes.
- The compatibility report bounds the selection, discloses deliberate
  semantic differences, and states that unselected tests imply no support.
- The embedded adaptations execute through River's public SQL API and add no
  production compatibility code or copied legacy fixture/canon.

## Independent review

The correctness adversary independently checked the import revision and URL,
GPL-2.0 notice, source/test tree hashes and counts, selected-file hashes and
line ranges, matrix semantics, SQL lifecycle, NULL/join/grouping behavior,
documentation boundaries, and snapshot handling of links, special files,
near names, empty trees, and exact regular `.DS_Store` metadata.

## Remaining boundaries

- A changed dependency, external reference, selected historical test, or tree
  algorithm requires a new ledger/matrix update and independent review.
- External datasets still require checksum-pinned approved acquisition before
  use.
- M5 remains active until U01/U02f/U03/U06 and the full acceptance matrix pass.
