River-owned callers use their existing named owners directly. Keep operation codes
private. Give the shared 128-bit division/remainder kernel one local owner, using
the existing caller-owned scratch with unchanged arithmetic. Preserve decimal
rounding, overflow/status behavior and output publication; add no allocations.
