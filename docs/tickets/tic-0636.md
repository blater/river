# Retain exact build and host-exclusion provenance for P0 diagnostics

Bind every promotion-grade River diagnostic to the exact built bytes and prove the shared host stayed free of overlapping builds and workloads.

## Design

Make tools/tps-test.sh retain the exact incremental or full build command, exit status, complete log, Git source and status fingerprints before build and run, Gradle and JDK identity, and a deterministic SHA-256 manifest of every launched classpath entry and file. Refuse evidence when source or manifest changes between build, server, client, and metadata publication. Before every build and workload, retain a broad host exclusion that distinguishes idle from busy Gradle daemons and detects River builds, tests, profiles, clients, servers, harnesses, and database workloads. Fail closed, preserve failed or interrupted evidence, and never expose secrets.

## Acceptance Criteria

Focused tests cover a clean current build, stale classes, source mutation, classpath mutation, missing or mismatched entries, failed build, active Gradle build or daemon, River workload or harness or profile overlap, process races, interruption, and immutable non-overwrite publication. A retained diagnostic independently reproduces every build, classpath, source, tool, and artifact hash and proves host exclusion for its full interval.
