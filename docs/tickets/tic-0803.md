# Implement exact recorded-process riverd stop

Implement stop against one resolved data directory using only its bounded runtime record and verified process identity.

## Design

Match bounded runtime and lock records by PID, process start instant,
`ProcessHandle` command, normalized data directory, and owner nonce; require the
live exclusive lock to remain contended without acquiring or stealing it; then
recheck the exact process immediately before SIGTERM. Wait for exit and matching
record removal; stale, malformed, reused, unlocked, unverifiable, or mismatched
state returns `NOT_OWNER` and sends no signal. Timeout never escalates.

## Acceptance Criteria

Real-process tests prove exact-owner stop, stale/reused PID rejection, timeout, simultaneous stop, listener-before-database closure, idempotent cleanup, and no data deletion.
