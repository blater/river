# R2: complete safe riverd instance operations

Complete verified stop, multi-instance discovery, audit recovery, credential lifecycle, and operational failure behavior.

## Design

Every mutation is scoped by one resolved data directory and exclusive ownership. No process scan, PID guess, implicit deletion, silent audit loss, or automatic SIGKILL is allowed.

## Acceptance Criteria

Exact-PID stop, ps, multiple instances, stale records, audit archive, credential recovery, interruption, timeout, and restartability pass their adversarial matrix.
