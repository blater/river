# Reuse retired page generations before growing frame residency

Current-frame selection returns the first null slot before checking later historical generations that are already below the oldest visible sequence. Repeated commits to the same page therefore allocate one frame and direct buffer per commit until the entire configured cache is populated, violating the warmed allocation contract and wasting admitted memory.

## Design

Preserve MVCC and eviction semantics. The existing preflight reclamation sweep
must retain the concrete empty frame objects it produces in an allocation-free
cache-owned chain. Current-frame acquisition consumes that chain before probing
unused capacity or ordinary eviction candidates. This keeps reclamation
O(configured frames) once per preflight and reuse O(1), while ordinary cache
misses retain their existing probe behavior. Add deterministic small-geometry
tests.

## Acceptance Criteria

Repeated same-page publication reuses an unpinned generation whose valid-until sequence is no newer than the oldest visible sequence even when unused slots remain; a pinned or still-visible generation is never reused; distinct current pages still grow into unused admitted slots; the focused warmed commit allocation test passes without raising its threshold; affected engine tests pass with no new arbitrary bound.
