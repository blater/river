# Define the 500 TPS interim promotion contract

Turn the user-visible 500 committed TPS target into one reproducible engineering contract before using it as a gate.

## Design

Declare workload implementation, profile, mix, isolation, durability, workers, warehouses, seed policy, host, warmups, sample length/count, minimum transactions, confidence statistic, correctness, provenance, and profiler exclusion.

## Acceptance Criteria

The contract distinguishes River-specific and shared-harness denominators, retains Alpha3's 1,000 TPS gate, contains no benchmark-sized production limit, and is accepted before candidate measurement.
