# Define the 500 TPS interim promotion contract

Turn the user-visible 500 committed TPS target into one reproducible engineering contract before using it as a gate.

## Design

Declare the river-harness workload implementation, riverd lifecycle contract,
profile, mix, isolation, durability, workers, warehouses, seed policy, host,
warmups, sample length/count, minimum transactions, confidence statistic,
correctness, provenance, and profiler exclusion.

## Acceptance Criteria

The contract makes river-harness the sole promotion denominator, keeps
River-specific TPS tooling diagnostic, retains Alpha3's 1,000 TPS gate,
contains no benchmark-sized production limit, and is accepted before candidate
measurement.
