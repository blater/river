# Run the riverd operational and recovery promotion matrix

Prove the composed start, restart, stop, ps, multi-instance, audit, credential, interruption, and failure behavior on the exact merged distribution.

## Design

Run focused suites, affected client/server tests, module dependency policy, installDist, reproducibility verification, slopmark review, and real process scenarios without concurrent builds or workloads.

Complete ADR-0003 filesystem promotion with unclean-shutdown and power-loss
recovery on the exact distribution/JDK/provider/kernel/ext4-or-xfs/device/mount/
storage-force tuple recorded by `tic-95e8`; a runtime API probe is not evidence
of durability.

## Acceptance Criteria

All lifecycle and security outcomes reconcile; no false readiness, process
misidentification, data loss, resource leak, secret leak, or unauthenticated
path remains. The qualified filesystem tuple passes exclusive/replacement
publication, source/destination alias recovery, every parent-force crash point,
and real power-loss recovery; otherwise the distribution remains unsupported.
Accepted evidence and checkpoint tag are pushed.
