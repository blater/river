# Inventory the existing authentication and launcher boundary

Map current protocol authentication, server audit, JDBC/client behavior, benchmark launcher, and lifecycle code against the riverd plan.

## Design

Identify reusable accepted owners, missing TLS/credential/instance behavior, insecure or duplicate paths, synchronous force costs, and concurrent worktree ownership without treating dirty code as delivered.

## Acceptance Criteria

The inventory names every plan requirement's current owner and status, identifies deletions and migration boundaries, and records source revisions without changing production behavior.
